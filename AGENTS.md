# Repository routing

This repository contains two independent workflows. Respect the user-selected host or version; do not merge their production defaults.

- Claude / original workflow: root `SKILL.md`, `references/`, and `templates/`.
- Codex workflow: `skills/codex-1920s-news/SKILL.md` and resources inside that directory.
- Do not change one version's instructions while updating the other unless the user requests both.
- Current user instructions override either version. Shared maintenance rules do not impose either workflow's defaults on the other.
- Keep private source chats and media out of public releases. Report actual checks and unverified boundaries honestly.
