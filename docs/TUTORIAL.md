# 用 AI 做一期 1920s 群聊新闻片

把一段群聊记录，做成 60–90 秒的黑白新闻片：报纸头条、电表跳闸、全息投影、天气板，配中文字幕和旁白。1920 年代新闻放映的风格，内容是你群里真实发生的事。

你不需要会写代码、不需要会命令行、不需要懂任何技术名词。**你需要的只有两件事：说清楚要什么，判断做出来的东西行不行。**

这份教程每一节都分两块：

- **交给 Agent** —— 复制一句话给它，剩下的它自己做完
- **你来判断** —— 只有你能做，AI 替不了

看的时候只读「你来判断」也行。等真要动手了，再复制「交给 Agent」那段。

---

## 先搞清楚谁干什么

| 谁 | 干什么 | 为什么 |
|---|---|---|
| **你** | 说清要什么（哪个群、哪天、多长） | AI 猜不出你的群是哪个 |
| **你** | 选题拍板：哪 8 件事值得上 | AI 挑得出，但不知道你想让谁露脸 |
| **你** | 看画面：有没有字被切、被压 | AI 没有眼睛，它只知道代码跑通了 |
| **你** | 判断能不能发：内容有没有问题、配乐吵不吵 | 发出去是你的名字 |
| **Agent** | 装环境、导数据、写文案、画场景、配音、配乐、渲染、合成 | 全是确定性工作，出错它会自己修 |
| **Agent** | 统计数字、核对原话、检查读字时长 | 比人快，而且不会累 |

一句话记：**凡是「对不对」的判断归你，凡是「怎么做」的执行归它。**

下面八节按顺序走。每节末尾有「怎么验收」——那是检查 Agent 有没有糊弄你的办法。

---

## 1. 开工：一句话说清四件事

一开始就说全，别让它一步步问你。它会问四件事：哪个群、哪天的记录、多长、什么风格。

**交给 Agent**

```
用 workbuddy-1920s-news 这个 skill，帮我做一期 1920s 风格的群聊新闻片。

群：<你的群名>
日期：昨天全天
时长：60 秒
风格：1920s 黑白新闻片

我不懂技术，所有命令你执行，需要装东西或者要权限就告诉我点哪里。
选题、画面、配乐这些要我拍板的地方，先问我，别自己定。
```

最后两行别省。第一行让它别把命令丢给你敲，第二行让它遇到要判断的地方停下来问你——不写这句，它可能一路做完才给你看，返工代价很大。

**你来判断**

- 群名报对了吗？同名群可能有好几个，它会列出来让你挑，挑人多的那个
- 「昨天」够不够？如果昨天的记录里没什么可讲的，宁可改前天，也别硬凑

**怎么验收**

它应该回你一句「确认四件事」之类的话，而不是直接开始装软件。如果它一句话不说就开始跑，说明它没打算问你，这时候补一句：「先告诉我你打算怎么做，我确认了再开始。」

---

## 2. 拿到数据：它去导，你确认范围

**交给 Agent**

```
把 <群名> 从 <日期> 00:00 到 23:59 的聊天记录导出来，存成文本。
导完告诉我：一共多少条、多少个人说话、从几点到几点。
```

**你来判断**

它导完会给你一组数字。你只需要看一眼合不合理：

- 条数和你印象里差不多吗？一个热闹的群一天几百条正常，只有三五条说明导错了
- 时间跨度是全天的吗？如果只有下午几小时，可能是它只导了一部分

**如果导不出来**

Windows 上这一步最容易卡。它可能会说「数据库文件不是数据库」或者「今天的消息找不到」。这两种都正常，不是它水平不行：

- **「不是数据库」**：微信电脑版有多个账号目录，它挑错了。让它按 `contact.db` 文件大小挑最大的那个
- **「今天的消息没有」**：微信还没把内存里的消息写进硬盘。这种情况别折腾，**改用前一天的记录**。片子晚一天发没关系，数据编出来就完了

**怎么验收**

问它一句：「这些数字是数出来的还是估的？」如果它说估的，让它重新数。

---

## 3. 选题：这一步你说了算

全部消息可能有几百条，最后上片的只有 8 条。挑哪 8 条，是整件事里最影响成片的一步。

**交给 Agent**

```
从这些消息里挑 8 件适合做成画面的事。

每件说清楚三样：
1. 讲什么（一句话）
2. 可以引用哪句原话（必须是原文，一字不改）
3. 能画成什么具体东西（报纸？电表？包裹？蓝图？）

挑完先给我看清单，我确认了再往下做。
```

**你来判断**

它给你的清单，一条一条过。三个标准，缺一条就换掉：

- **有画面**——能画成一个具体东西。「咖啡机炸了」能画一台炸开的机器；「大家讨论了产品质量」画不出来，再精彩也没用
- **有原话**——有一句短的、能直接引的。「第一次见这玩意冒烟」能用；「我觉得有待提高」不能用
- **有反差**——荒谬、反转、起哄、深夜发疯。平铺直叙的不行

另外看一眼：**有没有不该上的**。私人纠纷、别人的隐私、让人下不来台的玩笑，删掉。你群里的人会看这条片子。

**怎么验收**

随手挑清单里的一句原话，去聊天记录里搜。**搜不到就是它编的。** 这一步必做——AI 写文案时很容易把「大概意思」写成「原话」，看着特别顺，其实没人说过。

搜到了，再看是谁说的。它说是 A 说的，记录里其实是 B，也算错。

## 4. 文案：它写，你查原话

**交给 Agent**

```
按确认的 8 条写文案：每段一句旁白（12–22 字），画面上配引语牌。
引语必须逐字抄原文，错别字、谐音、表情符号都照抄，不要帮我改通顺。
写完跑一遍原话校验，把结果给我。
```

**你来判断**

- **旁白念起来顺不顺**。自己读一遍，拗口的地方让它改
- **旁白和画面上的字有没有重复**。同一句话字幕说一遍、画面又写一遍，看着像被当傻子
- **有没有「正确但无聊」的句子**。「群友们进行了热烈的讨论」——这种谁都能写，删掉

**怎么验收**

它会给你一个校验结果，最后一行应该是 `ALL FOUND`。不是这个词就是有问题，让它改。

但校验只保证「这句话在记录里出现过」，**保证不了「是这个人说的」**。张冠李戴还得你自己看。所以第 3 节那句「随手挑一句去搜」的功夫，这里再用一次。

---

## 5. 画面：它做，你看图

这一步是整件事的分水岭。代码跑通不等于画面能看。

**交给 Agent**

```
按文案做场景。做完出静帧联系表（stills/_sheet.jpg）给我看。
不要直接渲染全片，先让我看静帧。
```

**你来判断**

打开那张联系表（很多张小图的拼图），一张一张过。四个必查项：

- **有没有字被切掉**——标题超出画面、右边一栏看不见
- **有没有字被压住**——被别的元素盖住一半，或者被底部字幕挡住
- **有没有空画面**——切进来头几帧什么都还没出现
- **主体有没有出画**——该在中间的东西跑到画面外面去了

联系表上小字看不清，**可疑的那张打开原尺寸看**。

**怎么验收**

这一步没法验收，只能你自己看。但要记住：**AI 说「已修复」不等于修好了。** 让它改完重新出联系表，你再过一遍。返工三四轮很正常，第一次做八处返工是常态。

发现问题就描述现象，别用术语：

```
第 3 张，报纸右边被切掉了，第三栏看不见。
第 7 张，左下角的字被上面那个卡片压住了。
第 11 张，刚切进来的时候是空的，过了半秒才有东西。
```

---

## 6. 声音：它做，你听

**交给 Agent**

```
配音加配乐。旁白用中文播音，语速稍快。配乐用乐队风格，人声要比配乐明显高出来。
做完把整段音频给我听。
```

**你来判断**

- **听得清旁白吗**。配乐一响，旁白糊了就废了
- **配乐吵不吵**。默认是 BPM 200 的爵士风，比较热闹。你要是觉得闹，直接说「配乐换成轻一点的」
- **卡点对不对**。旁白说完，画面动作跟着来，还是慢半拍

**怎么验收**

它会报一个数字，比如「人声比配乐高 11.6 分贝」。8 到 12 之间就对了。低于 8 说明配乐压过人了，让它调。

**改文案之后必须重做这一步。** 改了字不重配音，后面所有卡点会全错位——而成片里不容易一眼看出来。跟它说「改完文案重跑配音和时间线」就行。

---

## 7. 出片：它渲染，你等

**交给 Agent**

```
渲染全片，然后合成音视频，最后压一个小体积版本给我发微信。
```

**你来判断**

这一步你基本没事干，渲染要十几分钟。可以去做别的，回来再看。

**怎么验收**

它做完会给你两个文件：

- `xxx.mp4`——能发微信的版本，十几兆
- `xxx-full.mp4`——高清母版，几百兆，留着以后用

如果它给了你四五个视频，问它哪个是最终交付的。**只留一个能发的**，其余让它归档到 `_raw` 文件夹。

---

## 8. 交付：你判断能不能发

**交给 Agent**

```
从成片里抽几帧给我看，确认和静帧一致。再写一份交付说明，写清楚：
素材来源和时间范围、数字怎么统计的、选了哪几条和为什么、
天气这类外部信息是哪天几点发布的、哪些画面是示意图、还有什么没解决的问题。
```

**你来判断**

- **抽帧和静帧一致吗**。合成时叠了胶片颗粒，可能让字更难读。这一步能发现静帧里看不出来的问题
- **内容有没有不能发的**。政治、低俗、真名、电话、地址、单位，一条都不能有。昵称可以用，但别让人顺着昵称找到真人
- **交付说明里有没有「需要你确认」的条目**。有就当场确认，别放着

**怎么验收**

拿手机放一遍，声音开一半。听得清、看得清、不尴尬，就能发。

## 附录 A：卡住了怎么跟它说

不用懂报错，照下面说就行：

| 情况 | 你就说 |
|---|---|
| 屏幕上一堆红字 | 把最后几行复制给它，说「报错了，你看下」 |
| 它说装不上某个东西 | 「这个装不上，有没有别的办法」 |
| 跑了很久没动静 | 「还在跑吗？卡在哪一步了」 |
| 它说成功了但没文件 | 「你说好了，但我找不到文件，路径发我」 |
| 做出来的东西不对 | 描述你看到的，别猜原因：「第 3 张右边被切了」 |
| 它一直问你问题 | 「你按默认的来，别问我了」 |
| 它一声不吭做完了 | 「以后要我拍板的地方先问我」 |

**不要说的话**：「这个怎么弄」「哪里错了」「帮我看看」——太模糊，它只能猜。

**要说的话**：你看到什么、你想要什么。「屏幕上出现一行红字，说找不到文件，我想要它接着往下做。」

## 附录 B：什么时候别用这套

- **群里没有能画的事**。全是「收到」「好的」「哈哈哈」，做出来是空壳。硬凑会显得很尬
- **涉及别人的隐私或纠纷**。片子会传开，你自己判断
- **要赶当天的热点**。当天消息常常导不出来（微信还没写盘），这套流程至少要隔一天
- **你不想花时间看画面**。静帧检查跳不过去，跳了必出事故
- **要求「专业级」**。这是手工作坊的活儿，一个人一天出一期，不是电视台水准

## 附录 C：想再玩点别的

**做成系列**。第二期复制第一期的工程，改个目录名就行。片头可以写「上期说到……」回扣上一期。

**换视觉风格**。渲染库自带 59 种风格：默片、浮世绘、水墨、木刻、剪纸、皮影、像素、乐高、60 年代特工片头……跟它说「换成木刻风格」就行。但要有心理准备：**换风格要重画全部画面**，文案配音能留，画面得重做，比做一期新的还费劲。

**改片长**。60 秒约 8 条，90 秒约 10 条。再长就拖了。

**出配套物料**。让它顺便出封面图和字幕文件（SRT），发视频号的时候用得上。

**定时出片**。跟它说「每周一早上八点，自动做一期上周的」。它会在 WorkBuddy 里建一个定时任务。

如果它说找不到资料，让它读仓库里这两个地方：

- `skills/workbuddy-1920s-news/SKILL.md`——执行顺序和硬参数
