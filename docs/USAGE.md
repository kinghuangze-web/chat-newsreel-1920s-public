# 使用手册

把一段群聊文字，做成 76 秒的黑白新闻片。这篇讲怎么用、怎么说、还能玩出什么。

---

## 一、这是什么

成品是一支模仿 1920 年代电影院新闻简报的短片：报纸头版讲当天最热闹的事，后面几件道具讲别的故事，每段一句解说，底部中英字幕，垫爵士乐。

实测一期：517 条群聊 → 76.8 秒成片，从拉仓库到出片 59 分钟。

**它擅长**：把散落的文字变成有节奏、有画面的短片，风格统一，每期不一样。
**它不擅长**：判断哪件事好笑、哪句话有梗、画面有没有被切掉一半。这三件事它做不了，见下面分工表。

### 活怎么分

| 事情 | 谁干 |
|---|---|
| 装环境、拉代码、跑渲染 | AI |
| 导出聊天记录 | AI（你授权） |
| 统计、排版面、配音配乐 | AI |
| **决定讲哪几件事** | **你** |
| **看画面有没有问题** | **你** |
| **判断能不能发** | **你** |

加粗的三行替不了：它不知道你们群里的梗，它没有眼睛，它不知道谁会被冒犯。

## 二、第一次用：一条提示词

新建对话，把下面这段改掉括号里的内容，整段发过去。

```
我要做一个 1920s 风格的群聊新闻片。

素材：微信群「（群名）」，时间（某月某日）全天。
成品：1 分钟到 1 分半，1920×1080 横屏，黑白胶片质感，
      中文解说，中英文字幕，爵士乐。

用 GitHub 上 kinghuangze-web/chat-newsreel-1920s-public 这套工作流，
渲染用 lemomo-ai/lemo-opuscar。

我不看代码。所有命令你执行，需要授权时告诉我点哪里。
每一步做完，用中文说：做成了什么、我该看什么、下一步是什么。
```

最后一句必须加。不加这句，它默认你懂技术，会扔一堆命令和英文日志过来。

**你只需要做一件事**：弹权限窗时点允许。它往工作目录外面写文件时会问。

**判断它真的开始了**：它会先用中文说环境情况，然后问你聊天记录在哪。如果它直接开始贴命令、贴英文报错，就是最后那句没生效，把这句话单独再发一次：

```
用中文说，我不看代码。
```

## 三、提示词库

按你遇到的场景挑一条，复制过去。括号里的内容换成你的。

### 3.1 换素材

不限微信群。日记、会议记录、工作群、读书笔记都行，格式是一行一条、带日期。

```
素材不是微信群，是（路径）里的一个文本文件。
格式是一行一条、带日期和发言人。用它做同样的片子。
```

素材少于 200 条会凑不出一期，硬做会很水。

### 3.2 定选题

先让它挑，你再定：

```
从这些消息里挑 8 件适合做成画面的事。每件说清楚：
讲什么、可以引用哪句原话（要原文）、能画成什么物件。
```

它挑完会给你一张表。**它会挑出你觉得无聊的，也会漏掉你觉得好笑的**——它不知道你们的梗。直接说：

```
第 3 件和第 6 件太弱，换掉。第 5 件换成（你想到的那件事）。
```

挑不出来就减数量，一期讲 4 件比硬凑 8 件强：

```
只留最强的 4 件，每件多给两秒。
```

### 3.3 写文案

四条红线，直接抄给它：

```
写文案守四条：
1. 引用的原话必须和原始记录一字不差，包括错别字和表情符号。
2. 所有数字从统计结果或原始记录里来，不许估，不许写「几百条」「几十人」。
3. 示意图必须标「示意」。
4. 不写政治、不写低俗、不写真名电话地址。
```

指定某一段怎么讲：

```
第 2 件这么讲：有人的插排插了四台设备，一开就跳闸。
重点突出「四台」和「跳闸」。
```

**核原话这一步不能省**。AI 编得很像真的，而且编出来的东西读着特别顺：

```
把你写的每一句引用，逐条回原始记录里搜一遍。
告诉我哪句找到了、哪句没找到。没找到的标出来。
```

没找到的就是错的，必须改。不要因为「读着通顺」就放过。

### 3.4 修画面

这一步是唯一 AI 帮不了你的。它会说「画面做好了」，然后给你一张联系表——全片关键帧缩成小图拼在一起。**你必须打开，一张一张看。**

看四样：字有没有被切、有没有空画面、主体有没有跑出画面、底部有没有被字幕挡住。

发现问题不用技术词，描述你看到的：

```
第 3 张，报纸右边被切掉了，第三栏看不见。
第 7 张，左下角的字被上面那个卡片压住了。
第 12 张，整个画面是空的。
```

它能听懂。改完让它重出：

```
按刚才说的改完，重新出静帧联系表，我要再看一遍。
```

**改八处是正常的。** 实测那一期改了八处，每一处都是看联系表发现的，代码检查一处都没抓到。不要觉得自己要求太高。

还有个自动检查可以跑：

```
跑一下读字时长检查，看有没有哪块字停留不够读。
```

它按每秒 4.5 个字算需要停多久。但这个检查只管「停得够不够久」，不管「有没有被挡住」。遮挡还得你看。

### 3.5 调声音

```
解说语速再慢一点，现在有点赶。
```

```
音乐太响了，盖住解说了，压下去让人声明显高于音乐。
```

第二条实测遇到过：第一版人声只比音乐高 1.1 分贝，几乎听不清；调到 9.8 分贝才正常。

### 3.6 出片

渲染画面约 10 分钟，合成音视频约 15 分钟。**这期间别关窗口，别以为卡死了。**

出来会有好几个文件，让它整理：

```
把半成品挪到 out/_raw 里，out 根目录只留成品和说明。
```

要字幕文件：

```
把字幕导出成 srt 文件，跟片子放一起。
```

### 3.7 返工

改了文案之后，必须重跑配音，否则画面跟声音错位：

```
改完文案，重跑配音和时间线，再重新出片。
```

漏了这句的后果：卡点全错，字幕跟画面不同步，而且成片里不容易一眼看出来。

## 四、进阶玩法

### 4.1 换视觉风格：59 种

这套渲染库自带 59 个风格，1920s 新闻片只是其中一个。适合做群聊新闻的：

| 风格 | 感觉 |
|---|---|
| `newsreel` | 1920s 新闻片（默认） |
| `news-package` | 现代电视新闻包装 |
| `caption-news` | 字幕新闻，极简 |
| `silent-film` | 默片，字幕卡代替旁白 |
| `rubber-hose` | 1930s 橡皮管卡通 |
| `midcentury-toon` | 1950s 中古卡通 |
| `ukiyoe` | 浮世绘 |
| `ink-wash` | 水墨 |
| `woodcut` | 木刻版画 |
| `papercut-red` | 红色剪纸 |
| `shadow-puppet` | 皮影 |
| `pixel-rpg` | 16 位像素 RPG |
| `brick-toy` | 乐高积木 |
| `spy-titles` | 60 年代特工片头 |
| `halftone-dossier` | 半调档案文件 |
| `whiteboard` | 白板讲解 |
| `dataviz` | 数据叙事 |

完整清单在渲染库的 `styles/` 目录。

**先说清楚代价**：换风格要重画全部场景，不是改个参数。文案、配音、时间线都能留，画面代码得重写。

```
我想换成浮世绘（styles/ukiyoe）。先评估：现有场景要重画多少、
大概多花多少时间。给我结论再动手，不要直接开始。
```

### 4.2 做成系列

第一期跑通之后，第二期开始有连续性：

```
这期是 EP.02。开头回扣上期一句，片尾预告下期。
另外换一半道具，别跟上期重样。
```

工作流的规范要求每期换一个「玩法」——换开场方式、换道具组合、换转场。**风格不变，内容结构变**，这样才有系列感。

### 4.3 改片长

```
压到 60 秒：砍到 4 条，每条 8 秒，旁白缩到 12 字以内。
```

```
拉长到 3 分钟：加到 12 条，中间加一次「急停」，只有字卡和一声鼓。
```

片长的物理限制是配音。旁白一句 12–22 字，对应 2.7–4.2 秒。超过 5 秒的句子必须拆。

### 4.4 月度 / 年度回顾

```
把这个月每天的记录合成一期回顾片：
按周分四段，每段挑一件最有画面的事，最后给一个月度数字
（总条数、最热闹的一天、说得最多的人）。
```

季度、年度同理。这类片子比日更更适合发朋友圈，因为信息密度高。

### 4.5 群友点播

```
这期做点播：群友点的是（主题）。把它当头条，其他照常。
```

或者让群友投票：

```
在群里发三条候选，让群友投票，得票最高的当头条。
```

### 4.6 换题材

这套流水线本质是「把文字变成片子」，素材来源不限：

```
素材是我孩子的成长记录（路径）。做成 1920s 新闻片，
语气别太新闻腔，温和一点。
```

```
素材是我们项目的 GitHub issue 和 commit 记录。
做成新闻片，标题严肃一点，别玩梗。
```

婚礼、旅行日记、读书笔记、公司年会总结都有人这么用。**注意**：题材换了，语气要跟着换，直接说「语气别太新闻腔」就行。

### 4.7 多语言

默认中文解说 + 中英字幕。要加语言：

```
字幕加一版日文，三语对照。配音还是中文。
```

配音换语言需要另一套 TTS 音色，不是一句话的事，先问它能不能做。

### 4.8 出配套物料

一条片子可以拆成一组内容：

```
从成片里挑 5 个关键帧导出成图片，我要做封面。
再把旁白文案整理成一篇文字版，每段配一张图。
```

配上 srt 字幕，就是一套可以分发到不同平台的内容。

### 4.9 定时自动出片

在 WorkBuddy 里可以设定时任务：

```
每天早上 10 点，自动把前一天的群聊做成新闻片，出片后告诉我文件路径。
```

适合日更群、公司内部日报。**前提**：前一天的消息必须已经落盘。当天的消息导不出来，见下面常见问题。

### 4.10 二创分发

成片 1280×720，10 MB 左右，直接发微信群没问题。要发短视频平台：

```
把成片转成竖版 9:16，主体居中，字幕放大一点。
```

注意：竖版会切掉左右片门，画面得重新排，不是简单裁切。

## 五、常见问题

**配置不高能做吗？**
8G 内存可以，渲染慢些。这套流程不用显卡。

**Mac 能做吗？**
能。告诉它「我用 Mac」，它会调整路径写法。

**聊天记录会泄露吗？**
素材只在本地处理，不上传。但成片里会有群友昵称，能不能接受你自己判断。

**它说「今天的消息导不出来」怎么办？**
不是它不行。微信把最近的消息先放内存，过一阵才写硬盘。两条路：关掉微信再打开让它写盘，或者改做昨天及更早的。

**做出来不好看怎么办？**
先分清是内容问题还是画面问题。不好笑、没意思 → 换选题，AI 救不了。挤、乱、空 → 让它改，改得动。

**改一处要重做多少？**
改文案要重跑配音和时间线，但不用重画场景。改场景要重渲染，但不用重做配音。只有换风格要全部重来。

**能不用微信吗？**
能。这套流程吃的是文本，一行一条带日期就行。

## 六、什么时候别用

**群里有敏感话题。** 做成片子传播范围比截图大得多。政治、纠纷、隐私一律不做。

**要当天出片。** 当天消息可能还没落盘，而且整个流程要一小时。

**素材少于 200 条。** 凑不出一期。

**你想要专业宣传片。** 这是模仿老电影的趣味短片，不是企业宣传。

**你不打算看静帧。** 不看一定出问题，这条没有捷径。

**你打算完全交给 AI。** 选题、看画面、判断能不能发这三件事它替不了。全交出去，出来的是「技术上没错、但没人想看」的片子。
