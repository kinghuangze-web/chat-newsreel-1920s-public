# 双版本公开发行范围

2026-10-27。本公开仓库从脱敏快照重新初始化，不带入原私有仓库的任何提交历史。

| 对象 | 内容与验证范围 |
|---|---|
| Claude 版 | 根目录入口，恢复原工作流；公开版移除真实案例目录、案例叙述和身份映射，保留通用方法与虚构模板，不合入Codex后续制作规则 |
| Codex 版 | `skills/codex-1920s-news/`，1.0.1；包含自己的编辑、制作、声音、运行和验收规范，内容与既有独立Skill一致 |
| 共享入口 | README分流，AGENTS只约束仓库维护边界，CLAUDE仅作原工作流入口链接；不以任何一套默认覆盖另一套 |
| 检查 | 两套入口通过Skill结构校验；Codex辅助工具10项回归通过；公开快照检查已知私有标识、路径、凭据格式和禁止分发素材类型 |
| 保留项 | 本仓库与Lemo-Opuscar许可署名、通用代码、虚构模板、依赖和运行契约 |
| 未验证项 | 本轮没有重新用新群聊制作视频，未执行新的完整视听验收；Claude原始模板的历史出片说明不代表本轮重新验证 |

根目录手册里的固定栏目、唱片模式、片尾卡及历史混音参数属于Claude原方法。Codex的主题承接、素材处理、配乐入口和声音验收更新只在Codex子目录维护。用户当前明确要求优先于两版默认。

实际制作需另备授权聊天导出、Lemo运行时、字体、语音和图片能力及所需媒体。移除真实案例不移除虚构模板和运行接口；也不因此宣称本仓库是独立一键出片程序。
