# 实测参照：EP.01

这份文件不解释方法。它记录一条已完成的片子的全部参数，作为对齐基准。

规范怎么要求，看 `editorial.md`（选题、结构、旁白）和 `production.md`（工程、时间线、转场）。这里只有「实际做成了什么样」。文案内容不在其中，只保留结构和参数——拿到自己的素材后，按同样的段位数、同样的时长分配、同样的道具密度往里填。

片子规格：1920×1080 / 24fps / 76.8 秒 / 有声。

## 1. 素材与统计口径

| 项 | 值 |
|---|---|
| 时间窗口 | 单日 01:36 – 23:04 |
| 消息数 | 517 |
| 发言人数 | 30 |
| 每小时峰值 | 16 时，146 条 |
| 最热 10 分钟 | 16:20 段，29 条 |
| 单条最多 | 91 条 |

口径：517 只算真人发言。系统提示（入群、撤回、红包提示）另计 9 条，不进统计、不上屏。全片只用这一个口径，交付说明里写明。

## 2. 段落表

12 段，共 64 小节，76.8 秒。

| 段 | 小节 | 秒 | 道具 | 职能 |
|---|---|---|---|---|
| `logo` | 4 | 4.8 | Art Deco 字卡 + 光束 | 片头 |
| `paper` | 7 | 8.4 | 报纸头版 | 头条，最长 |
| `meter` | 6 | 7.2 | 指针瓦特表 + 配电箱 | 有数字的冲突 |
| `holo` | 6 | 7.2 | 桌面全息投影 | 有梗的想象 |
| `card` | 3 | 3.6 | 急电字卡 | 急停，最短 |
| `crate` | 6 | 7.2 | 等轴木箱 + 对比标签 | 观点 |
| `ledger` | 5.5 | 6.6 | 账簿 + 滚动计数器 | 金额 |
| `gift` | 8 | 9.6 | 包裹 + 便利贴 + 印章 | 复读起哄 |
| `weld` | 7.5 | 9.0 | 工程蓝图 + 焊接火花 | 深夜 |
| `weather` | 4.5 | 5.4 | 天气板 | 固定栏目 |
| `endlogo` | 3.5 | 4.2 | 结束 ident | 收尾 |
| `endcard` | 3 | 3.6 | 字幕卡 | 片尾 |

时长分配的规律：头条最长（8.4 秒），急停最短（3.6 秒），其余 6–9 秒。**每段时长必须是 0.6 秒的倍数**（半小节），否则和配乐错拍。

## 3. 视觉参数

```js
const W = 1920, H = 1080, GX = 220, GW = 1480, GH = 1080, FPS = 24;
```

- 片门：左右各留 220px 黑边，画面有效区 1480×1080。
- 左上角时间卡占位：`{x0:48, y0:56, x1:600, y1:170}`。标题不能进这块。
- 底部字幕带：约 `y > 900`。道具底部内容不能进这块。

四套字体，分工固定：

| 字体 | 用在哪 | 字号档 |
|---|---|---|
| Limelight | 片头英文、英文大标题 | 84 / 64 / 60 / 56 |
| Oswald | 数字、英文标签、尺寸标注 | 30 / 28 / 26 / 24 |
| Noto Serif SC | 中文标题、报纸正文、印章 | 200 / 84 / 72 / 64 / 58 / 36 |
| Noto Sans SC | 中文小字、注释、示意标注 | 30 / 28 / 26 |

色彩：灰度底，单一暖白高光。描边用近黑，不做彩色渐变。

## 4. 时间结构

- BPM 200，一小节 1.2 秒，一拍 0.3 秒。
- 全片 49 个 hit（切点、盖章、贴纸、落箱、火花）。平均每 1.5 秒一个动作，但分布不均：头条段 4 个，急停段 1 个。
- 20 句旁白，8 张地点卡。
- 旁白句长 12–22 字，对应配音 2.7–4.2 秒。超 5 秒的句子必须拆。

## 5. 转场

6 处，全部落在小节线上：

| 从 → 到 | 类型 | 出 / 入（秒） |
|---|---|---|
| paper → meter | wipe | 0.16 / 0.16 |
| holo → card | blinds | 0.02 / 0.30 |
| card → crate | irisopen | 0.02 / 0.28 |
| ledger → gift | flip | 0.14 / 0.14 |
| gift → weld | clock | 0.17 / 0.17 |
| endlogo → endcard | fade | 0.30 / 0.30 |

另有 3 处 iris 收黑：`logo` 段末、`weld` 段末、`endlogo` 段首。iris 只用在「段落整体结束」的位置，段内切镜不用。

规律：进急停用慢入（0.30），出急停用快出（0.02）。急停本身就是节奏断点，进出速度必须不对称。

## 6. 道具骨架

六个新道具的实际构图参数。坐标基于 1920×1080 画布。

**指针瓦特表**：圆心 `(372, 452)`，半径 236。刻度弧从 `-π×1.24` 到 `π×0.24`。指针从 3.15 推到 4.2 再回落。表盘文字放在圆心下方 104px 处——指针是半径，靠近圆心的任何文字都会被扫过。

**配电箱**：`(872, 150)` 起，548×540。四个闸位横排，间距 120，每个 86×296。闸刀从 ON 位滑到 OFF 位，行程 146px。

**等轴木箱**：`{x0:340, y0:344, w:700, h:420, sk:112}`。两组标签分别 slam 到箱面 x+150 和 x+410，中间盖一个手绘的「≠」。

**账簿**：840×660 账页，右侧 300×190 计数器。数字从 0 滚到 20，滚动时长与旁白同步。

**包裹**：620×470。TO / FROM 各一行，三张便利贴依次贴上，最后盖印章。

**蓝图**：铺满 1480×1080。白色线稿，三条尺寸线，火花在 `(877, 424)` 闪四次。

## 10. 与规范的偏差

如实记录，不当作范例：

- **报纸没有用「飞入」**。规范里的开场是报纸旋转飞入，这次改成满幅宽 + 纵向摇移（报头 → 大标题 → 引语框）。原因是竖版报纸按高度适配后两侧全空，推近又会切掉三栏。
- **配乐用合成音源，不是采样库**。当时 GitHub release 不可达，改用纯物理建模合成黄铜、簧管、钢琴、钟琴。音色不如真实采样厚。
- **报纸推近时，左上角时间卡压住报头左侧一两个字**。卡片是模板固定位置，报头居中无法避开，接受了这个瑕疵。
