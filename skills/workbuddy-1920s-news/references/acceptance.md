# 验收清单

交付前逐条过。前四条是机器检查，后面是人眼和人脑。

## 机器可查

### 1. 引语全部命中

```sh
python tools/check_quotes.py work/chat.txt
```

输出必须是 `ALL FOUND`。屏幕上出现的每一句引语都要能在原始记录里逐字找到，包括错别字和表情符号。

有一项找不到就是不合格。改引语，不要改校验脚本。

### 2. 读字时长

```sh
cd <LIB>
node core/render/readcheck.mjs "$(cygpath -w <项目>)"
```

规则是每块字从完整进入画面起，停留时间 ≥ `(汉字数 ÷ 4.5) + (其他字符 ÷ 15) + 1.5` 秒。

必须 0 项不合格。退出码非 0 就是没过。

### 3. 时间线无警告

```sh
python tools/timeline.py
```

输出末尾必须是 `OK`。OVERLAP、SPILL、LONG 三类警告一条都不能留。

### 4. 响度

合成时 `mux.sh` 会自己打印实测值：

```
I: -14.0 LUFS
LRA: 5.3 LU
Peak: -1.0 dBFS
```

目标 −14 LUFS、真峰 ≤ −1 dB。它会自己警告偏离，不用另写检查。

人声与配乐的比例另测一次：有人声的段落应该比纯配乐段落高 8 dB 以上。

## 人眼要看的

### 5. 联系表逐帧

打开 `stills/_sheet.jpg`，一张一张过。重点看四样：

- 有没有字被切掉、被压住、被别的元素盖住
- 有没有空画面（切进来头几帧什么都还没出现）
- 主体有没有超出片门
- 底部内容有没有被字幕带切

联系表只能看构图。可疑的单张要打开原尺寸看。

### 6. 成片抽帧复核

从渲染好的 mp4 里抽几帧，确认成片和静帧一致：

```sh
for t in 3.0 20.6 28.2 55.5; do
  ffmpeg -y -loglevel error -ss $t -i out/video.mp4 -frames:v 1 "out/qc/f_$t.jpg"
done
```

胶片颗粒是在合成阶段叠的，可能让细节更难读。这一步能发现静帧里看不出来的问题。

## 事实要核的

### 7. 数字能回溯

屏幕上每个数字，都要能指回统计结果或某一行原文。

统计口径要一致：消息数是否含系统消息、时间窗口从哪到哪、人数怎么算的，交付说明里写清楚。

### 8. 外部信息有出处和时间

天气、价格、公告这类外部信息，标注来源和发布时间。片子里的数据可能是几小时前的，读者需要知道。

### 9. 示意图有标注

手绘的、简化的、非写实的画面，角落标「示意」或「示意图」。别让观者以为那是实拍或实拍转绘。

### 10. 边界内容

- 没有政治敏感内容
- 没有低俗内容
- 没有真名、电话、地址、单位
- 昵称可以用，但不要跟现实身份关联

## 交付形态

### 11. 目录分层

```
out/
├── <name>.mp4          # 交付物
├── <name>-full.mp4     # 母版
├── DELIVERY.md         # 说明
├── qc/                 # 抽帧
└── _raw/               # 中间产物
```

中间产物不进交付层。

### 12. 说明写清楚

`DELIVERY.md` 至少包含：

- 素材来源与时间窗口
- 统计口径
- 选了哪几条、为什么选
- 外部信息的出处和发布时间
- 哪些画面是示意
- 已知限制和需要用户确认的点

## 不合格怎么办

按严重程度：

| 级别 | 例子 | 处理 |
|---|---|---|
| 阻断 | 引语对不上、数字没出处 | 必须改，不能交付 |
| 严重 | 字被切、空画面、旁白粘连 | 必须改，重渲染 |
| 一般 | 构图偏、比例不协调 | 记入说明，下期改进 |
| 提示 | 音色不够厚 | 记入说明，不算缺陷 |

前两级不通过不交付。后两级如实写进 `DELIVERY.md`，不要藏。
