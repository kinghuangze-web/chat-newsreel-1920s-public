# 短串场纪实快报 · Brief Cameo

可选风格 `brief-cameo`，版本 1.0.0。与 [Codex 1920s 工作流](../../SKILL.md) 配合使用，不替换原入口、核心排程或其他宿主的默认风格。

新闻画面居中展开：经典影院片头建立节目感，事件原图或视频提供证据，清晰文字说明状态。主持 IP 只在问候、必要承接和告别时出场，用短动作完成交流，随后退场；整期听到同一位主持。

## 调用

把整个 `codex-1920s-news` 子目录安装为 Skill，保留其中的 `styles` 目录。对制作助手说：

> 使用 $codex-1920s-news，选择 styles/brief-cameo/README.md 的“短串场纪实快报”。新闻素材占主体，IP 少量串场，全片固定一个已选声线。按本期内容决定镜头与动作，交付可播放视频和独立验收记录。

直接读仓库时，先读 Codex 入口，再读本文件。该目录是显式选择的风格补充，没有修改自动发现逻辑，也没有向已安装的其他副本自动同步。

## 构图与动作

| 层 | 表现与约束 |
|---|---|
| 节目片头 | 保留旋转地球、探照灯、银色字；片头完成后再出现角色 |
| 新闻主体 | 一张完整新闻画布；原素材、事实数字、流程或状态卡按事件选择；不同事件改变动作链与构图 |
| 主持串场 | 角落或留白处短暂出现，不固定占栏，不长期挂名牌；重要图像、数字和字幕始终优先 |
| 角色动作 | 一个连续的正面形象可做局部挥手、点头、尾部轻摆；按身体结构定位控制点，出现、动作、收势、退出连贯 |
| 做旧与文字 | 胶片颗粒、暗角和抖动作用于背景；字幕、人名、数字、日期与状态保持清晰稳定 |
| 结束 | 完整告别后自然收尾，不再追加清单页或等待尾奏 |

角色可先以画高约 16%—20%、单次 1—3 秒、整片合计少于约 10% 的出场时间试排。这些是起调范围，不能代替实际遮挡、主次与动作检查。内容拥挤时可以更小、更少或移位；不要为满足“三次”而强插角色。动作还需在分享尺寸可辨，不能小到只剩噪点。

同一张图整体平移、三视图轮换都不能代替角色自身动作。二维局部网格形变是轻量选择，不宣称骨骼绑定、逐字口型或生成式视频。轮廓变形过大时，改用用户提供的可用分层/动作素材，而不是继续扭曲静态图。

## 声音与同一时钟

1. 先确定唯一声音来源：用户指定的干净参考片段，或服务已提供的固定 speaker ID。保持参考、模型、口音与声线参数一致；记录引用文件 hash 与请求结果，记录中不要包含密钥或参考音频 base64。
2. 在服务限制允许时，优先把完整定稿一次连续合成，返回后保存为唯一旁白母带。逐栏目重新用“温柔女声”等文字生成，不能证明是同一个人。不同 TTS 的参考、ID 与限长能力应按实际服务核实。
3. 必须分段时，保持同一身份条件与相邻上下文，并逐段比较音色、咬字和接缝；如中段变声，整段修复或重做连续旁白，不能偷偷换一个近似声音。
4. 从真实解码音频建立句段边界，所有镜头、字幕、串场、音乐和结束点共用同一时间线。对齐结果保留原始识别词及时间戳，另做内容核验。
5. 素材原声默认不进入这一单主持设计；如本期确需原声引用，必须明确标为引用，并核对最终混音。配乐固定克制电平或按完整段落缓变，避免随音节反复起伏。

本风格允许快速信息节奏，不固定每期必须 1.3 倍。用户要求 1.3 倍时，明确它是相对哪个版本的速度：优先一次生成合适语速，或对唯一母带做一次保音高变速，再重建时间线；不要 TTS 加速后又给成片重复乘速。全片连续合成能减少重选声线，但不能替代最终听审。

当前核心 `scripts/schedule.py` 接收逐句 WAV，并未因本补充获得连续母带自动对齐能力。可以依据经复核的句段边界从同一母带切出 WAV，再交给原脚本；要保留母带的原始停顿和连续性时，应直接用复核后的绝对时间生成本期 timeline。两条路径都需要验证实际音轨与时间线，不把风格文档当作已实现的对齐器。

## 证据素材与审片

每句转述对应原记录及上下文；每个新闻媒体对应具体消息或原始链接和实际文件。自报成绩保留归属，预告、正在收尾、已上线、已复现分别表达。未解开的图片可以省略，或依据已知文字画清楚标记的示意；不要用无关缓存文件填空。

先检查片头交接、角色运动峰值、新闻特写、密集文字与末帧，再看完整画面序列。登记所有重要文字及主持区域，检查出现时窗、变换后边界和字幕遮挡；几何检查无法判断视觉重心，仍需取样观看。最终分享版尤其要检查小字、低对比来源行和角色动作是否可辨。

最终验收分别记录技术、内容、画面、声音的状态，并绑定实际 MP4 hash。声音记录应同时区分“单声轨/固定参考实现”和“全片听感/参考贴合”，未听审就保留 `NOT_CHECKED`。不要给未验证类别统一盖章。

## 局部组件与虚构小样

- [cameo-layer.mjs](cameo-layer.mjs)：浏览器 Canvas 2D 组件。原尺寸离屏网格形变，整层一次缩放与淡入淡出；通过回调接入调用者的角色控制点，不内置私人角色。
- [demo.html](demo.html)：12 秒确定性静音交互小样，只有代码绘制的虚构主持标志和新闻示意，不加载在线资源。
- [check.mjs](check.mjs)：借用调用者已有 Lemo/Chromium，检查实际 Canvas 像素、边界时窗、重复渲染和异常输入。
- [pitfalls.md](pitfalls.md)：本风格提炼的通用故障及处理边界。
- [VALIDATION.md](VALIDATION.md)：公开小样实际验证范围。

可用已有静态 HTTP 服务打开本目录的 `demo.html`。需要本地服务时：

```sh
python -m http.server 8765 --directory skills/codex-1920s-news/styles/brief-cameo
```

然后打开 `http://127.0.0.1:8765/demo.html`。完成后停止自己启动的服务。程序化检查：

```sh
node skills/codex-1920s-news/styles/brief-cameo/check.mjs <lemo-root> <evidence-directory>
```

依赖已有 Node 20+、Lemo 的 `core/render/page.mjs` 及其浏览器依赖；Chrome 路径按原工作流设置。组件只需现代浏览器 Canvas 2D；不安装软件、不调用语音 API。完整 MP4 仍依赖本期授权素材、声音、字体、渲染和混音流程。未完成端到端新片与全片听审时，不能宣称该小样验证了它们。
