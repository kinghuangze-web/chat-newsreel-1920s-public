# 画面、素材与声音

## 事件素材转成新闻片

保留经典地球与探照灯，后续镜头可用报纸、电报、剪报、工作台、办公室版画与日历。Art Deco标题、黑白层次与清晰字幕构成统一语言；不靠把每个事件都摆在同一张纸上实现一致性。

原图/视频先匹配消息，再记录作者、范围与处理。用户补图可以补足表现，但明确它是补充材料；不要倒推出聊天窗口里不存在的数字、时间或操作。

界面转绘时：

1. 写清需要保留的结构和语义（如办公室工位、任务卡、任务标题、完成状态），把风格变化与事实内容分开。
2. 用黑白版画/雕版印刷/电报室材质改造视觉。图像工具可能改字，输出后逐一核对关键文字。难以保持时裁掉无关小字、在代码层重绘准确标题；不要把乱码放大当正文。
3. 先全景建立多个工位的空间关系，再连续推近真正有信息的详情。镜头在同一素材内推进，不是假装操作了软件。
4. 屏幕只简短标“转绘”或“示意”等必要信息；完整工具、提示词、来源和加工边界放外置SOURCES。

## 清晰文字与运动包络

按“画面/胶片质感 → 清晰文字 → 转场遮罩 → 字幕”组合。文字独立于颗粒不等于独立于镜头：光圈关闭时必须同时遮住画面字，否则字会浮在黑场上。

Canvas零半径路径可能成为空操作，导致主持人的第一帧闪成全画面。`assets/guards.mjs`使用明确的矩形遮挡和偶奇填充；半径零时整块片门为黑。替换时检查关闭、全闭、初开与开完的真实编码帧。

重要文字注册真实变换后的边界：标题、引语、数字、署名、状态、图片内重要标签以及推近中的卡片。列expected IDs，与全时间采样实际seen核对；少注册不能通过。局部裁切过程允许文字移出镜头，但完整事实呈现阶段必须留有可读时间，不能用“裁切后未注册”掩盖全程不可读。

字体测宽只判断边界；还需看重叠、遮挡、缩小后的字形和做旧。取样覆盖入场最大缩放、纸张最高点、旋转边缘、推近终点、转场中点和结尾。文字不出界不能证明整体画面合格。

## 统一时钟

先获得真实配音长度。把场景、桥接句、正文、媒体播放、转场、字幕、音效和音乐绑定同一时间线。媒体九秒节选若要完整展示，场景结束至少覆盖其实际播放范围；桥接增加的时间不能挤掉片尾字。

改字幕读法、场景顺序或开场长度后重新排程，不把所有时间手工加常数，也不只修改画面不重混音。导出脚本读当前时间线；抽帧也由当前事件时间生成，避免沿用旧版取样点。

## 配乐和人声

用户指定版本时核对实际音源与编曲，不能把普通上传源称为内部播出母带。BGM不自动变成唱片故事。

先确定实际节目使用的主题、乐句起点和小节关系，再规划循环与片尾。不得为了让原曲尾奏赶上片尾倒推一个任意起点；完整乐句在选定告别处平稳淡出，优于牺牲开场。不同上传版可能裁过前奏、变速或已含重复，报道的完整版时间戳不能直接套用；记录来源、文件hash、对应区间和实际节目比对依据，相似度只证明其覆盖的匹配范围。

循环在同一乐句和节拍相位衔接，保留实际周期；交叉淡化不能修复错拍。无新增剪口不等于源文件本身连续。源文件、起点、顺序变更后重测节奏，并导出实际混音开头、每个接缝、典型中段和结尾。承接以叙事为先，不宣称所有切镜都已卡准强拍。

有持续旁白的片子优先固定、克制的BGM电平。确需ducking时按完整语句或段落平缓变化，检查增益摆幅、回升速度和频次；禁止用瞬时振幅门限让音乐随音节或短停顿反复大幅回弹。开头避免高电平硬进，做适合起句的柔和进入。时代感不要求全程放映噪声、唱针声或重击。

逐句峰值归一不等于响度一致。对处理后的完整语音片段测响度，校平句间主观音量并控制峰值；保留自然句内变化。单声道和双声道测量口径分开记录，短句估计有限，不盲追小数一致。轻度播音处理优先于重失真、窄带或颤音。

先定本期总响度目标，再用静态增益和必要限幅控制；常用-16至-14 LUFS、峰值<=-1 dBTP仅作技术参考，不强迫每期-14，也不反复动态归一来拉扯整曲。平均声部差、整片LUFS、ASR分数都不能证明舒适、节奏正确或完整听审。保留ASR原转写和同音/数字归一差异，有疑点就记录。
