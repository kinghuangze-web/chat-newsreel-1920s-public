# Codex 1920s新闻联播

交付可播放MP4与可编辑工程。以“经典影院片头 → 简短主持锚点 → 有主题关系的事件镜头 → 完整告别”建立节目语言；事件数量、顺序、长度和配乐服从本期内容。借用Lemo-Opuscar的MIT渲染基础，编辑方法、素材编排与检查契约在本Skill内独立维护，不宣称上游代码为原创。

## 创作判断

- **先读完整上下文，再写热点。** 确定谁、何时、对象、状态和实际建议。引语逐字，转述保留动作、条件与归属；自报成绩不是普遍结论，预告不是已发生。
- **先设计承接，再做转场。** 相邻事件用同一主题、一个待解问题、场景转移或栏目转换相连。可调整顺序；不能靠“接下来”反复报幕，不能把独立群友的实践编成因果。桥接句、画面变化、下一事件首句一起审。
- **画面来自事件。** 数字增长、发布反转、人工确认、进度观察、开源分享、日程预告分别适合不同动作链。换道具仍是同一构图不算变化。
- **原素材优先。** 取得并对应原图、视频、音频；缺少核心媒体时先找匹配来源或按已知事实改编，用户已给图时不要继续用泛化仪表代替。界面可转成黑白版画办公室，保留工位、任务卡、状态等含义，先全景建立空间再推近细节；转绘不是软件原始截图，也不是可操作录屏。
- **字要比做旧更清楚。** 关键文字单独在胶片层上绘制；人名、时间、数字和状态不抖、不被颗粒擦坏。图内重要文字也需要边界与分享尺寸检查。

## 本系列默认与本期契约

经典旋转地球、探照灯、银色标题先出现，用户提供IP随后短暂自报。BGM默认只在声音中出现，不自动增加唱片、曲名或唱针。默认告别读完直接结束，来源和许可证放外置说明，不加制作清单、统计页或空等尾奏。天气不默认带入。以上为本系列默认，用户当前明确要求可覆盖。

指定熟悉的节目配乐时，先核编曲与实际节目使用的乐句，再决定本片起点和循环；不能为了保留原曲尾奏倒推任意切入点。稳定的低电平配乐和逐句响度一致优先于追随音节反复升降；最终听审独立于技术指标，详见[声音规则](references/production.md#配乐和人声)。

先恢复已确认的群、账号、窗口、IP、音乐与结尾偏好，不重复问。只在授权范围取数；本地查询取尽不等于服务器记录完整。本机有多个微信时绑定准确账号与目标群。原始聊天及私人媒体留本地；在线TTS、图像编辑等仅发送任务需要的已授权输入，不能宣称全部处理都离线。

## 制作与修订

1. 整理本期契约、完整素材窗口及热点来源；生成简短`RUNDOWN.md`，每条包含事实、实际建议、证据媒体、动作链和与前条的关系。读[编辑与承接](references/editorial.md)。
2. 编写旁白、读法、字幕与来源映射；取得实际配音时长后再排镜头。`scripts/schedule.py`可用解码WAV生成统一时钟、字幕和检查结果；输入契约见[运行与数据](references/runtime.md)。
3. 利用已有Lemo运行时制作独立工程，按事件选择构图和素材。新增图像或转绘使用环境提供的图像工具；可编辑的原生代码元素直接修改。先检查关键构图、运动峰值和新媒体特写，再完整渲染。实现注意见[画面与声音](references/production.md)。
4. 改口播或时长时联动镜头、字幕、转场、音效、音乐取段与结束点，废止失效报告。没有相关改变的证据可复用；音频复用须对应同一解码音轨，不能仅重命名旧报告。
5. 验证最终分享版和高清版。`scripts/inspect_video.py`检查解码、规格、响度并绑定hash，自动检查不会给内容、观看或听审判PASS。按[验收与交付](references/acceptance.md)分别记录证据。

普通授权修订持续完成到可播放文件，无须为常规实现新增批准关卡。用户要求先审分镜时遵从；系统返工不限制一次修几个问题。

## 随包资源与边界

- `assets/episode.example.json`与`durations.example.json`：虚构数据契约，后者是测试时长，不能当成真实TTS证据。
- `assets/guards.mjs`：光圈零半径遮罩、变换后文字边界与覆盖检查，可复制进工程；光圈在清晰文字层之后执行。
- `scripts/check_guards.mjs`：利用调用者指定Lemo运行时的Chromium验证这些画布不变量。
- `scripts/schedule.py` / `inspect_video.py`：独立Python辅助工具；前者仅标准库，后者还需PATH中的FFmpeg/FFprobe。

这是**完整制作Skill与可执行辅助工具**，不是自带模型、微信导出器、字体、音乐、IP或独立一键渲染器。Lemo渲染、语音、图像编辑与授权素材是显式依赖；缺少某项就报告具体未验证边界，不因文档齐全宣称能完成新视频。

不自动向群发送、发布视频或同步私有案例。仅当用户要求分享/同步时提交通用规则和代码；来源、上游许可与实际完成状态如实保留。
